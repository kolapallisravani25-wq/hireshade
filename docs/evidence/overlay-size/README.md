## Summary of measured results (full table: docs/CAPTURE_MATRIX.md)

Affinity transitions: 11/11 PASS (WDA 0x11 for BANNER/READING, preset/resize/move,
simulated display change, compat mode on/off; private-off asserts the intentional
0x0). See affinity-*.json.

Capture paths (A/B vs hidden baseline, same path):
- GDI CopyFromScreen: ON 0.004% / 0.28% diff vs baseline; OFF 16.45% / 7.32%.
  -> HONORS exclusion at BANNER and READING (READING residual 0.28% noted).
- Chromium desktopCapturer screen: ON 0.104% / 0.117%; OFF 5.44% / 5.57% -> HONORS.
- Chromium desktopCapturer window sources: ON thumbnail 0x0 (0-byte PNG),
  OFF 1366x252 (banner) / 1366x690 (reading) -> protected window yields no pixels.
- PrintWindow: ON all-black (mean luma 0, 100% black, flag2 rejected); OFF content
  (mean 21.66 / 8.59) -> no content leak observed via PrintWindow.
- ffmpeg gdigrab recordings: 4 x 2 s mp4 (BANNER/READING x ON/OFF) plus frames.
- ffmpeg ddagrab (DXGI Desktop Duplication): ON vs hidden baseline 49.8% pixels
  differ, OFF 42.9% -> OBSERVED: DXGI ignores WDA_EXCLUDEFROMCAPTURE.

Other states:
- Compatibility mode at READING: affinity 0x11 (PASS); GDI capture saved.
  Runtime mode = opaque #0b0d12 scrim + no blur/rounded compositing; true
  transparent:false surface is created on the next launch (Electron transparent
  flag is creation-only). Runtime window recreation is opt-in
  (HIRESHADE_COMPAT_RECREATE=1) after it crashed Electron during evidence.
- DPI simulation (--force-device-scale-factor=1.5, separate instance):
  affinity 0x11 PASS, display 607x341 DIP.
- Self-check UI ids/status: see docs/CAPTURE_MATRIX.md section 3.

## Key files

- summary.json — machine summary generated by scripts/capture-matrix/summarize.mjs.
- affinity-*.json — per-transition GetWindowDisplayAffinity assertions.
- gdi-*.png, desktopcapturer-*.png, printwindow-*.png — stage frames.
- gdigrab-*.mp4 + frames — A/B screen recordings (BANNER/READING ON/OFF).
- ddagrab-* — DXGI A/B recordings + frames.
- diff-*.json/.png — measured pixel differences.
- main.log / main-supp.log / main-dpi-sim.log — Electron main logs with every
  reassert reason+counter.
- userdata*, userdata-dpi — isolated profiles used for the runs.
