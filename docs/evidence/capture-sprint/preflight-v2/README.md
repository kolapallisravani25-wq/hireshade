## Fact

- 0x11 (WDA_EXCLUDEFROMCAPTURE) is invisible on good paths (GDI, PrintWindow,
  desktopCapturer, gdigrab) and leaks on DXGI Desktop Duplication.
- 0x01 (WDA_MONITOR) is black on GDI/PrintWindow/DXGI.
- Therefore black box mode is a **targeted mitigation, not an upgrade**: it is
  never selected by default and is offered only for known-DXGI/high-risk
  single-display setups.
