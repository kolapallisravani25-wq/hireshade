ANSWER: (B) PREVIEW-ONLY / NO DEVICE
------------------------------------
The W4 gaze virtual camera NEVER registered as a selectable device (no
"Gaze Virtual Camera", "HireShade Virtual Camera", OBS Virtual Camera, or any
other name). It was shipped behind the preview/fallback as a deferred sink:
  - the only runtime sink the product can obtain is DeferredVirtualCameraSink
    (status "deferred", capabilities.realCameraDevice = false);
  - the DirectShow/CMIO/v4l2 adapters are typed stubs that FAIL CLOSED with
    the exact build+registration reason (no fake success);
  - no DirectShow filter DLL / INF / VCXPROJ exists in the repo, no COM
    registration code exists, and the host has no such device to open;
  - the product UI exposes no virtual-camera output at all; only the standalone
    preview page/canvases and the demo flag consume the gaze pipeline, and
    neither imports a virtual-camera sink.

Runtime proof on this Windows host (see section 4): ffmpeg DirectShow enumeration
lists only the physical "Integrated Webcam"; the DirectShow video-input
aggregation key has no Instance entries; the only camera device is the USB
webcam; named virtual-camera opens fail with I/O error, while the control
physical-webcam open succeeds.

6. WHAT WOULD MAKE THIS ANSWER (A) REGISTERED SELECTABLE DEVICE
================================================================================
A future build would have to:
  1. build an MSVC x64 DirectShow COM filter DLL (DirectShow BaseClasses);
  2. elevate and run regsvr32 on it (or ship a signed installer that writes
     HKLM/HKCU CLSID + CLSID_VideoInputDeviceCategory + the video-input
     DeviceClasses mapping);
  3. restart Zoom/Meet/Teams so they re-enumerate cameras;
  4. then ffmpeg -list_devices would show a gaze-named video device and
     ffmpeg -f dshow -i video="Gaze Virtual Camera" would open it.
None of these exist on this branch/host: 0 native projects, 0 DLLs, 0
registration entries, 0 devices; the W4 commit itself names the deliverable
"mock virtual-camera sink" and the code fails closed to preview-only.

FINAL: (B) PREVIEW-ONLY / NO DEVICE.
